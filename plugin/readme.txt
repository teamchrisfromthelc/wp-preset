== Description ==

Keep "Tested up to" current. wordpress.org treats a value behind the
latest release as an error and drops the plugin out of search results, so
it needs bumping each time WordPress ships a major version — even in a
release that changes no code. Use the major version only (6.9, not 6.9.1).

Describe what the plugin does, in prose. This is the text the plugin's
wordpress.org page leads with, so write it for someone deciding whether to
install rather than for someone who already has.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it through the Plugins screen in WordPress.
